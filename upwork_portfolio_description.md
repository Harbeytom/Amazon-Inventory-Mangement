# Upwork Portfolio Description

## Amazon Inventory Management: FBA & FBM Stock Tracking

I created a sample inventory management portfolio demonstrating how Amazon sellers can organize product stock, monitor estimated inventory coverage, and prioritize replenishment reviews across FBA and FBM workflows.

### Included
- Sample FBA and FBM inventory trackers
- SKU and ASIN-placeholder organization
- Estimated days-of-cover calculations
- Reorder-point and suggested-quantity examples
- A spreadsheet workbook and simulated case study

**Transparency note:** This is a demonstration project using fictional data. It is not connected to a live Amazon account and does not claim client results. Any real inventory recommendations should be validated against current Seller Central data and the seller's operating assumptions.
